Tambah Menu Baru

Isi pada tiap pilihan = jumlah satuan dasar di dalam 1 pilihan itu. Contoh: Pak isi 10 bungkus → isi 10, Bungkus → isi 1, Dus mamy poko isi 12 renceng → isi 12. Menjual pilihan apa pun otomatis memotong stok bersama ini.
Barang bernama sama otomatis jadi satu menu. Untuk mengubah harga dus, pak, atau renceng, klik Edit pada menunya lalu ubah harga di baris pilihan yang sesuai. Perubahan nama/harga tidak mengubah transaksi lama.
Ubah harga massal

Berlaku untuk barang yang tampil sesuai pencarian dan kategori di bawah (0 pilihan). Contoh: cari "dus" lalu naikkan 5%, atau pilih kategori Rokok lalu tambah Rp 500.

Konversi satuan otomatis (stok bersama dus / pak / bungkus)

Untuk menu yang nama pilihannya memuat jumlah isi, misalnya Pak isi 10 dan Bungkus, atau Dus isi 12, sistem menyusun satu stok bersama secara otomatis: tambah 10 pak berarti 100 bungkus, dan menjual 1 bungkus memotong stok yang sama. Menu yang isinya belum jelas (misal "Dus" tanpa angka) dilewati, atur manual lewat tombol Edit. Status lacak stok tidak diubah.

Tips: harga jual dan modal bisa langsung diubah di kolom pada daftar di bawah. Ketik angka baru lalu tekan Enter atau pindah kolom, otomatis tersimpan.

Data Toko

Sinkronisasi Antar Perangkat

Hubungkan ke database Supabase (gratis) supaya riwayat transaksi, produk, dan stok sama di semua HP/komputer, dan tetap aman walau satu perangkat rusak atau datanya terhapus. Aplikasi tetap bisa dipakai tanpa internet; transaksi dikirim otomatis begitu online.

Cara menyiapkan (sekali saja)
  1. Daftar di supabase.com, buat project baru.
  2. Buka SQL Editor, tempel SQL di bawah, klik Run.
  3. Buka Project Settings → API. Salin Project URL dan anon / publishable key, isi di kolom di atas, klik Simpan & Hubungkan.
  4. Di perangkat lain, buka aplikasi ini, tempel kode sambungan lalu klik Pakai kode ini.

      
      
Catatan keamanan: siapa pun yang memiliki URL dan key ini bisa membaca dan mengubah data toko. Jangan tulis keduanya di file yang diunggah ke GitHub; isi lewat halaman ini saja (tersimpan di browser masing-masing perangkat).

    

  


  

    
Katalog Barang (barang.sql)

    
Katalog dari database barang sudah tertanam: . Impor ulang memperbarui nama, kategori, dan harga barang yang kodenya sama; stok dan barang lain tidak berubah.

    

  


  

    
Ekspor Database (.sql)

    
Unduh data toko sebagai file SQL yang bisa diimpor ke MySQL/MariaDB (phpMyAdmin). Tabel: produk, penjualan, penjualan_item, pengeluaran, pengguna, pesanan, pesanan_item. Tabel dengan nama yang sama akan ditimpa saat impor.

    

  


  

    
Backup & Pulihkan Data

    
Data tersimpan di browser perangkat ini. Jika sinkronisasi belum aktif, data ikut hilang bila data browser dihapus. Lakukan backup rutin dan simpan file-nya di flashdisk atau Google Drive.

Jendela cetak tidak terbuka

  
Biasanya terjadi bila file dibuka lewat pratinjau atau aplikasi lain, bukan langsung di browser. Ada dua cara:
